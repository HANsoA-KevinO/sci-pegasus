# 比赛方向三对齐

依据用户提供的 GOAI《赛道三：前沿探索 AI for Research》手册（PDF 物理页 21–27，当前规划版本）。最终规则仍应以组委会正式发布版本为准。

## 基本任务（必做，方向内 50%）

系统必须完成一条可审计的文献发现链路：

1. 根据研究方向或问题自主检索并筛选材料科学文献。
2. 抽取材料成分、结构、性能、模拟方法、合成条件等结构化信息。
3. 识别未充分探索方向、矛盾结论或缺失知识连接。
4. 输出含 Research Gap、文献交叉引用和证据链的结构化报告。

主要评分关注 Research Gap 的准确性、新颖性、可操作性，文献溯源完整性与可信度，以及报告结构和可读性。手册推荐 Sciverse、MinerU，并指出 Sciverse MCP/Skill 调用记录可自然形成可审计证据链。Sci-Pegasus 将 Sciverse 元数据发现、全文 chunk 证据召回、`doc_id` 全文落盘和 `unique_id` 引用图扩展分为来源绑定的意图工具，并用 schema v2 `operation/source` 审计保留调用证据。arXiv 原始 PDF 由 `ArxivFetchPaper` 保存后，默认用无需密钥的本地 `pdf-parse/PDF.js` 解析；若未来需要 MinerU、Docling 或模型解析，只替换内部后端，不改变 Agent 工具语义。

通用科研发现策略在此工具层之上按文献成熟度组合 `review_update`、`adjacent_tension` 与 `hybrid`，用 Workspace C/E/G/H 账本保存证据、Gap 状态与可证伪假设，并以独立复核和明确停止理由约束结论。它保持材料体系与进阶路线中立，详见 `RESEARCH_STRATEGY.md`。

## 进阶路线（任选其一，方向内 50%）

- 路线 A：构效关系发现。必须把搜索/优化算法与 LLM 深度结合，且用文献和材料数据库区分新知与已知。可使用 Materials Project、OQMD、NOMAD 交叉验证。
- 路线 B：模拟方法创新。在标准 benchmark 或真实材料体系上展示精度、效率、创新和可复现性。
- 路线 C：合成路线与工艺设计。生成或优化有文献/化学原理支撑的路线，并展示可解释推理与验证证据。

现阶段 Project Guide 保持路线中立。基于现有 Agent/检索/记忆底座，路线 A 与未来的自进化多智能体搜索最自然衔接，但在科学问题、可得数据和验证条件确定前不在代码中锁死。

## 提交物

- 基本任务：文献调研报告、Research Gap 清单、交叉引用、证据链、系统说明。
- 进阶路线：对应路线的发现清单/代码与 benchmark/合成方案及验证证据。
- 最终：完整技术报告与可复现代码或容器。

## 合规

商业 API、闭源模型、外部数据、费用假设、权限、替代性与迁移成本必须披露。基于已有项目开发时，必须说明原项目来源、团队贡献、新增创新点和协议兼容性。详见 `ORIGIN_AND_LICENSE.md`。
