# 来源、贡献与许可状态

## 来源

Sci-Pegasus 从用户持有的 Pegasus 项目完整副本开始清理和改造。当前阶段的主要新增贡献包括：

- 移除科研绘图/Canvas/生图专用产品面和依赖；
- 改为材料科学文献驱动发现的 Project Guide 与工作区；
- 建立独立端口、数据库、Cookie、内部路径、Docker 网络/卷与媒体前缀；
- 保留并重新定位 durable Agent Runtime、记忆、队列、审计和通用证据资产；
- 新增 Sciverse/arXiv 文献发现、原文物化、本地 PDF 解析、全文定位和 provenance 审计；
- 新增持久多 Agent Team、动态任务/P2P、监督与等待恢复、路径级 Workspace CAS、权限/预算/遥测和结果发布审批；
- 增加比赛对齐、隔离、多 Agent V1 和后续自进化 loop 文档。

后续提交比赛时应继续列出每个阶段新增的文献 adapter、科学抽取/验证、multi-agent 编排和评测贡献。

## 许可状态

本副本根目录当前没有发现可作为权威依据的 `LICENSE` 文件。旧文档中曾出现相互冲突的许可表述，因此不能据此断言 Pegasus 或本项目采用 MIT、私有许可或其他具体协议。

在原项目权利人书面确认之前：

- 不要公开发布、再许可或宣称本仓库为 MIT；
- 不要删除第三方依赖自身的版权与许可声明；
- 比赛材料中如实披露“基于 Pegasus 副本开发”和团队的实际新增范围；
- 在复赛提交前完成源项目权属、第三方依赖和数据/API 许可审计，并加入正式 LICENSE/NOTICE。
