# 动态团队、监督与停止

## 何时创建 Agent

只有满足至少一项时创建：

- 可独立检索的 Gap cluster、材料体系或相邻性轴；
- 可并行的全文抽取或条件归一；
- 需要与原分析隔离的反例、novelty 或科学复核；
- 当前 Agent 的上下文已不适合承载新的证据分支。

不要为了角色完整创建 Agent。锚点综述发现、post-review 更新、引用图扩展、响应矩阵、冲突归因、相邻文献扩圈和独立复核都是任务类型，不是固定身份。

## 首条任务模板

```text
目标：要减少的具体不确定性。
边界：材料、时间、问题与排除项。
方法：应加载的 Skill 和检索/抽取要求。
证据标准：全文位置、独立来源、不得由摘要定论。
输入：C/E/G/H IDs、搜索审计或 workspace 路径。
产物：私有文件路径与结构。
协作：可直接联系的 Agent 和需回传的引用。
完成条件：可验收事实。
停止条件：饱和、不可得或明确阻塞。
```

普通首轮工作直接放入 `Agent` prompt。只有存在依赖、正式验收或独立预算时再使用 Task，避免重复描述同一工作。

## 监督与通信

- 复用职责相符的 idle Agent，而不是创建同名替代者。
- 用 `SendMessage` 发送问题、里程碑、blocker、C/E/G/H IDs 和具体文件引用。
- 让成员之间直接解决局部接口问题；Root 不做人工消息总线。
- Root 在方向变化、证据冲突、错误外推或阻塞时干预；普通进度只观察。
- 成员自然结束即待机。需要追问时继续发消息，不把“本轮完成”等同于 close。

## 独立科学复核

实质性最终研究报告必须经过一次持久记录的 `scientific-review`，这是一条完成门槛，不是可选润色步骤。

- **多 Agent 或争议任务**：把复核交给未主导相关检索、证据综合或 Gap 判定的成员。复核者直接读取研究 scope、全文位置、检索审计和 C/E/G/H artifacts，不能只根据 Root 或原作者的摘要判断。
- **窄 Root-only 任务**：Root 可在证据账本与报告草稿冻结后自行执行独立对抗性 pass。复核阶段重新从原始 artifacts 检查结论，并明确记录它与初始综合阶段的边界。
- **记录位置**：优先写入 `analysis/scientific-review.md`；若使用成员复核，也可保留不可变 Agent result 或成员私有复核 artifact，但最终报告必须给出可精确定位的 ID/路径。
- **最低记录**：reviewer、reviewed scope、as-of date、读取的原始路径、抽查 E IDs、复核的 C/G/H IDs、critical/major/minor findings、disposition、修订动作和未决项。
- **返修闭环**：critical/major finding 导致关键状态或证据链变化时，先修改公共 artifacts，再复核受影响部分。无法消除的问题必须降级为 `provisional` 或 `indeterminate`，不得无记录地通过。

没有复核记录时，只能交付明确标记的 draft 或中间结果，不能声称实质性最终报告已完成。

## 停止条件

每个高优先级 Gap 至少覆盖：

- cutoff 后的关键词/日期查询；
- 可用时的 CITATIONS/RELATED_WORKS 分支；
- 最新性敏感主题的 arXiv 分支；
- 关键论文全文核查；
- 版本和独立来源去重；
- 反向 novelty 检索。

连续两轮新的 query family 或图扩展均没有带来新合格独立来源、Gap 状态变化、新 moderator/boundary 或新实质冲突，可以判定边际信息趋于饱和。

新兴主题默认扩展到 R1/R2；只有 transfer bridge 清楚才进入 R3。连续两圈可比性下降且没有新张力时停止扩圈。

资源或访问限制也可以停止，但必须记录：未完成分支、失败原因、对结论的影响和恢复条件。

## 失败模式

- **任务重叠**：给每个 Agent 独立问题、语料边界或复核责任。
- **只分检索不分综合**：预留冲突归一和独立复核任务。
- **成员结果无法合并**：统一 C/E/G/H IDs、条件字段和产物模板。
- **循环搜索**：按 query family 记录新增信息，而不是只记录命中数。
- **用“没有找到”代替停止证据**：公开检索范围、日期、图扩展和全文缺口。
