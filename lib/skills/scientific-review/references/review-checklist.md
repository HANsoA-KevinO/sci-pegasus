# 科学复核清单

## A. 范围与方法

- 用户命题是否被操作化为材料、结构、机制、方法、endpoint 和条件？
- 选择 `review_update`、`adjacent_tension` 或 `hybrid` 的理由是否与文献密度一致？
- 路径变化是否保留了历史和依据？

## B. 锚点与检索

- 主锚点是否 scope 最匹配，而非只因引用高？
- 是否有 1–2 篇真正独立的校准综述？
- Review 类型、全文和 cutoff 是否确认？
- `impact_boost` 是否被错误称为 JIF？使用时是否设置 `sort_by_year: "none"`？
- Post-review 是否覆盖关键词、时间、CITATIONS、RELATED_WORKS 与适用的 arXiv？
- 搜索审计、分页和失败分支是否公开？

## C. Evidence 与 Claim

- E 是否为原子 Observation，能定位到全文？
- 关键 Methods、Results、Discussion 和 Limitations 是否都被考虑？
- 单位、endpoint、baseline 和条件是否可比？
- 作者解释与 Agent inference 是否分开？
- C 是否列出支持、反驳、限定与独立来源组？
- 是否把同一研究版本或二手转述误算为复核？

## D. Gap 与 Hypothesis

- Gap seed 是否经过 cutoff 后更新和反向 novelty 检索？
- `answered` 是否有多条独立 primary evidence 和反证处理？
- `unresolved` 是否带 as-of date 与检索范围？
- 全文或可比性不足时是否使用 `indeterminate`？
- `partially_answered` 与 `conditionally_answered` 是否保留 remaining scope？
- H 是否包含变量、方向性预测、替代解释和反证条件？

## E. 相邻性与冲突

- 是否逐项记录八个相邻性轴？
- 每篇相邻论文是否有 transfer bridge 和 analogy break？
- R3 是否只用于 provisional Hypothesis？
- 冲突是否在归一材料、工艺、环境、测量、数据、模型和尺度后仍成立？
- 根因是否标记 observed / author-proposed / agent-inferred / experimentally-tested？

## F. 报告与停止

- C/E/G/H 交叉引用是否可解析？
- 是否公开 as-of date、检索覆盖、解析限制、未决项和停止理由？
- 连续扩展的边际信息是否真的降低，还是工具/访问失败？
- 负结果和异议是否被保留？
